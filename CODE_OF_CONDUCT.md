# Código de Conduta do PrintGest ERP

Ao participar deste projeto, você concorda em seguir este Código de Conduta.

## Nosso Compromisso

Nosso compromisso é criar um ambiente acolhedor, independente e respeitoso para todos os participantes, independentemente de:

- Gênero, identidade ou expressão de gênero
- Idade
- Orientação sexual
- Afiliação racial ou étnica
- Religião ou crenças
- Deficiência
- Experiência ou background técnico
- Nível de contribuição (desenvolvedor, documentação, testes, etc.)

## Comportamento Esperado

- **Respeitar opiniões divergentes** e experiências diferentes
- **Dar e receber feedback** de forma construtiva
- **Respeitar o direito de escolha** do grupo
- **Focar no que é melhor** para a comunidade
- **Mostrar empatia** para com outros membros da comunidade

## Comportamento Inaceitável

Os seguintes comportamentos são considerados inaceitáveis:

- **Assédio** ou assédio sexual
- **Agressão** verbal ou física
- **Discriminação** ou preconceitos
- **Ataques pessoais** ou ofensivos
- **Desrespeito** a decisões do projeto
- **Privacidade violada** (informações pessoais)
- **Spam** ou atividades fora de contexto
- **Atividades ilegais** ou criminosas

## Aplicação

Os responsáveis pelo projeto estão comprometidos em aplicar este código de conduta. Eles terão o direito e a responsabilidade de remover, editar ou rejeitar comentários, contribuições e outras atividades que violem este código.

## Reportando Problemas

Para reportar violações do código de conduta:

1. **Contate um mantenedor** via:
   - E-mail: conduta@printgest.com.br
   - Mensagem privada no GitHub

2. **Inclua**:
   - Descrição da violação
   - EVIDÊNCIAS (prints, links, etc.)
   - Nome da pessoa ou grupo envolvido
   - Eventuais comentários anteriores

3. **Confidencialidade**: Sua identidade será protegida

## Escopo

Este código de conduta se aplica a:

- Repositórios oficiais do PrintGest ERP
- Grupos de chat oficiais (Discord, WhatsApp, Slack)
- Fóruns e comunidades oficiais
- Eventos relacionados ao projeto
- Interações em nome do projeto

## Atribuição

Este Código de Conduta é inspirado no [Código de Conduta do Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), versão 2.1, e adaptado para o contexto do PrintGest ERP.

Para sugestões de melhoria, abra uma issue ou envie um pull request.
